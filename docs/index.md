# 我的技术文档

你好，我是苏可。这是我在开源软件课程中搭建的个人文档网站，用来练习从 Markdown 源文件到公开网页的完整发布流程。

这次实践最重要的不是把四个页面放到网上，而是让更新过程可以重复：我只需要修改 `docs/` 中的内容并推送到 `main`，GitHub Actions 就会重新构建并发布网站。

## 网站内容

- [关于本项目](about.md)：项目目标、工具分工和目录说明。
- [使用指南](guide.md)：本地检查、提交和部署的具体步骤。
- [API 参考](api.md)：一个用于练习技术文档写法的接口示例。

## 这次实践的流程

```text
修改 Markdown → 推送到 main → Actions 构建 → Pages 发布
```

我会在部署完成后再做一次内容修改，确认新的推送能够自动触发工作流，而不是只验证第一次运行。
