# 关于本项目

## 项目目标

这个仓库用于完成课程的 GitHub Pages 个人实践。网站源码和实验报告都保存在公开仓库中，方便从提交记录、Actions 日志和最终网页三个位置核对结果。

## 技术组成

| 工具 | 在本项目中的作用 |
| --- | --- |
| Markdown | 编写四个页面的正文、表格和代码示例 |
| MkDocs Material | 把 `docs/` 中的 Markdown 构建成静态网站 |
| GitHub Actions | 在每次相关文件推送后自动安装依赖、构建和部署 |
| GitHub Pages | 托管构建好的静态文件并提供公开网址 |

## 目录怎么分工

- `docs/` 保存我实际维护的文档源码。
- `site/` 是 MkDocs 构建出来的结果，每次都能重新生成，所以加入了 `.gitignore`。
- `.github/workflows/deploy.yml` 定义自动构建和部署的步骤。
- `report/` 保存实验过程、关键截图和我的理解。

我一开始容易把“源码”和“网页文件”混在一起。实际操作后更清楚了：日常修改的是 `docs/`，`site/` 只是构建产物，不需要手工编辑或提交到 `main`。
